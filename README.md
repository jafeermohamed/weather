# AETHER Weather Pro\n\n1. Extract the ZIP and open the `AETHER-Weather-Pro` folder in VS Code.\n2. Run `npm install`.\n3. Copy `.env.example` to `.env` and add your OpenWeatherMap API key.\n4. Run `npm run dev`.\n\nIncludes a responsive multi-section dashboard, interactive 3D Earth, city search, light/dark theme, Celsius/Fahrenheit toggle, current conditions, metrics and five-day forecast. The forecast API provides 3-hour intervals, not true hourly observations. A Vite `VITE_` API key is visible in the browser; do not commit `.env`.\n
